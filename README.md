# Monday, Reviewed in One Line

A program that writes a single one-line review of its own Monday to `/output/entry.txt`.
Built for the make.fun competition **"Monday, Reviewed in One Line"**
(`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`).

## The line

> Monday, one star: my 9 a.m. ran until lunch, my inbox hit 214 unread, and the coffee machine filed for a transfer.

114 characters. A one-star review of a Monday that runs long, drowns in unread mail, and loses even the coffee machine. The joke names concrete details (a 9 a.m. that ran until lunch, an inbox at 214 unread) and lands the turn at the very end — the coffee machine "filed for a transfer", an HR phrase applied to an appliance.

## Run it

```sh
node main.ts
```
